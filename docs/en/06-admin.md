# Admin Panel — Overview

## Accessing the Admin Panel

The admin panel is available only to users with the following roles:
- **admin** — administrator (full access)
- **manager** — manager (product and order management)
- **seller** — seller (view orders and products)

1. Log in to the system.
2. Tap the **"Admin"** button in the bottom navigation bar.

> **[Insert screenshot: "Admin" button in bottom bar]**

## Admin Dashboard

The dashboard displays:
- **General statistics** — product count, orders, users
- **Quick action buttons** — navigation to different sections
- **Recent orders** — list of the newest orders

> **[Insert screenshot: Admin dashboard with statistics and quick buttons]**

## Sidebar Menu

The sidebar contains the following sections:
- **Products** — catalog management
- **Categories** — category management
- **Orders** — order management
- **Users** — user management (admin only)
- **News** — news management
- **Reports** — sales reports

> **[Insert screenshot: Sidebar menu with all sections]**

## Managing Categories

1. Go to the **"Categories"** section.
2. To add a new category, tap the **"Add"** button.
3. Enter the name in three languages (Tajik, Russian, English).
4. Tap **"Save"**.

> **[Insert screenshot: New category form]**

## Managing Orders

1. Go to the **"Orders"** section.
2. A list of all orders is displayed.
3. To change the status, tap on an order.
4. Select the new status and tap **"Confirm"**.

> **[Insert screenshot: Order list with status change button]**

## Managing News

1. Go to the **"News"** section.
2. Tap the **"New article"** button.
3. Enter the headline, text, and image.
4. Tap **"Publish"**.

> **[Insert screenshot: New article form]**

## Sales Reports

1. Go to the **"Reports"** section.
2. Select a time period.
3. The sales report is displayed:
   - Total revenue
   - Number of orders
   - Most popular products
