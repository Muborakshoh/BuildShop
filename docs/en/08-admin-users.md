# User Management

> ⚠️ This section is available only to **administrators**.

## User List

1. In the admin panel, go to the **"Users"** section.
2. A list of all users is displayed:
   - Name
   - Email
   - Role (admin, manager, seller, customer)
   - Registration date
   - Status (active/inactive)

> **[Insert screenshot: User list in admin panel]**

## Adding a New User

1. Tap the **"New user"** button.
2. Fill in the following fields:
   - **Full name** — first and last name
   - **Email** — email address
   - **Password** — password for the user
   - **Role** — select a role
   - **Phone** — phone number (optional)

> **[Insert screenshot: New user form]**

3. Tap **"Save"**.

## Changing a User's Role

1. In the user list, tap the **"Edit"** button.
2. Select the new role:
   - **customer** — buyer (no admin panel access)
   - **seller** — seller
   - **manager** — manager
   - **admin** — administrator
3. Tap **"Save"**.

> **[Insert screenshot: Role selection in user edit form]**

## Deactivating a User

1. In the user list, tap the **"Deactivate"** button.
2. The user will no longer be able to log in.

> **[Insert screenshot: Deactivate button]**

## Searching Users

1. In the search field, enter a name or email.
2. Results are filtered automatically.
