# Кассир (Точка Продаж)

## Доступ к кассиру

Страница кассира доступна пользователям с ролями **seller**, **manager** и **admin**.

1. Войдите в систему.
2. В нижней навигационной панели нажмите кнопку **«Кассир»**.

> **[Вставьте скриншот: Кнопка «Кассир» в нижней панели]**

## Интерфейс кассира

Страница кассира состоит из двух частей:
- **Левая часть** — каталог товаров для быстрого выбора
- **Правая часть** — корзина продажи с выбранными товарами

> **[Вставьте скриншот: Страница кассира с каталогом и корзиной]**

## Добавление товара в продажу

1. Нажмите на товар в каталоге слева.
2. Товар добавляется в корзину продажи.
3. Измените количество кнопками **«+»** и **«−»**.

> **[Вставьте скриншот: Добавленный товар в корзине продажи]**

## Быстрый поиск товара

1. В поле поиска введите название товара.
2. Товар появится мгновенно.
3. Нажмите для добавления в корзину.

> **[Вставьте скриншот: Быстрый поиск на странице кассира]**

## Завершение продажи

1. Добавьте товары в корзину.
2. Проверьте общую стоимость.
3. Нажмите кнопку **«Продажа»**.
4. Выберите способ оплаты (наличные / карта).
5. Нажмите кнопку **«Подтвердить»**.

> **[Вставьте скриншот: Кнопка «Продажа» с общей стоимостью и выбором оплаты]**

## Печать чека

1. После завершения продажи нажмите кнопку **«Печать»**.
2. Чек будет подготовлен для печати.

> **[Вставьте скриншот: Образец чека для печати]**

## История продаж

1. Нажмите кнопку **«История»**.
2. Отобразится список всех сегодняшних продаж.

> **[Вставьте скриншот: История продаж со списком транзакций]**
