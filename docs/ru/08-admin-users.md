# Управление Пользователями

> ⚠️ Этот раздел доступен только **администратору**.

## Список пользователей

1. В панели администратора перейдите в раздел **«Пользователи»**.
2. Отобразится список всех пользователей:
   - Имя
   - Email
   - Роль (admin, manager, seller, customer)
   - Дата регистрации
   - Статус (активен/неактивен)

> **[Вставьте скриншот: Список пользователей в панели администратора]**

## Добавление нового пользователя

1. Нажмите кнопку **«Новый пользователь»**.
2. Заполните следующие поля:
   - **Полное имя** — имя и фамилия
   - **Email** — адрес электронной почты
   - **Пароль** — пароль для пользователя
   - **Роль** — выберите роль
   - **Телефон** — номер телефона (необязательно)

> **[Вставьте скриншот: Форма добавления нового пользователя]**

3. Нажмите кнопку **«Сохранить»**.

## Изменение роли пользователя

1. В списке пользователей нажмите кнопку **«Редактировать»**.
2. Выберите новую роль:
   - **customer** — покупатель (без доступа к панели админа)
   - **seller** — продавец
   - **manager** — менеджер
   - **admin** — администратор
3. Нажмите кнопку **«Сохранить»**.

> **[Вставьте скриншот: Выбор роли в форме редактирования пользователя]**

## Деактивация пользователя

1. В списке пользователей нажмите кнопку **«Деактивировать»**.
2. Пользователь больше не сможет войти в систему.

> **[Вставьте скриншот: Кнопка деактивации]**

## Поиск пользователей

1. В поле поиска введите имя или email.
2. Результаты фильтруются автоматически.

> **[Вставьте скриншот: Поиск пользователей с результатами]**
