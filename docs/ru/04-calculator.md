# Калькулятор Стройматериалов

## Зачем нужен калькулятор?

Калькулятор помогает рассчитать необходимое количество материалов для строительства или ремонта. Например:
- Сколько кирпичей нужно для стены?
- Сколько мешков цемента нужно для фундамента?
- Сколько квадратных метров плитки нужно для двора?

## Использование калькулятора

1. В нижней навигационной панели нажмите кнопку **«Калькулятор»**.

> **[Вставьте скриншот: Кнопка «Калькулятор» в нижней панели]**

2. Выберите тип материала (например: кирпич, цемент, плитка).

> **[Вставьте скриншот: Список типов материалов]**

3. Введите размеры:
   - **Длина** — в метрах
   - **Высота** — в метрах
   - **Ширина** — в метрах (если требуется)

> **[Вставьте скриншот: Поля ввода размеров]**

4. Нажмите кнопку **«Рассчитать»**.

5. Отобразится результат:
   - Необходимое количество материала
   - Стоимость по ценам магазина

> **[Вставьте скриншот: Результат расчёта калькулятора с количеством и ценой]**

## Добавление результата в корзину

1. После расчёта нажмите кнопку **«Добавить в корзину»**.
2. Рассчитанные материалы будут добавлены в вашу корзину.

> **[Вставьте скриншот: Кнопка «Добавить в корзину» в результатах калькулятора]**
