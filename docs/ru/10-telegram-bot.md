# Telegram-бот

## Начало работы

1. В Telegram найдите бота (имя бота узнайте у администратора).
2. Нажмите кнопку **«Start»** или отправьте команду `/start`.
3. Бот автоматически зарегистрирует вас.

> **[Вставьте скриншот: Экран Telegram с кнопкой Start]**

## Главное меню

После запуска отобразится главное меню с кнопками:
- 🛍 **Товары** — просмотр каталога
- 🛒 **Моя корзина** — просмотр корзины
- 📦 **Мои заказы** — просмотр заказов
- 📰 **Новости** — чтение новостей
- 👤 **Мой профиль** — личная информация
- 📞 **Контакты** — контактная информация магазина

> **[Вставьте скриншот: Главное меню бота со всеми кнопками]**

## Просмотр товаров

1. Нажмите кнопку **«🛍 Товары»**.
2. Отобразится список категорий.
3. Выберите категорию.
4. Товары отображаются с ценой и фото.
5. Для следующей страницы используйте кнопки **«◀️»** и **«▶️»**.

> **[Вставьте скриншот: Список товаров в Telegram-боте]**

## Добавление в корзину

1. Под товаром нажмите кнопку **«В корзину»**.
2. Выберите количество.
3. Товар добавлен в вашу корзину.

> **[Вставьте скриншот: Кнопка «В корзину» под товаром]**

## Оформление заказа

1. Нажмите кнопку **«🛒 Моя корзина»**.
2. Проверьте товары в корзине.
3. Нажмите кнопку **«Оформить заказ»**.
4. Отправьте адрес доставки сообщением.
5. Заказ будет подтверждён.

> **[Вставьте скриншот: Корзина в Telegram-боте с кнопкой оформления]**

## Отслеживание заказов

1. Нажмите кнопку **«📦 Мои заказы»**.
2. Отобразится список всех заказов со статусами.

> **[Вставьте скриншот: Список заказов в Telegram-боте]**

## Команды бота

Доступные команды:
- `/start` — запуск бота
- `/help` — список команд
- `/menu` — показать главное меню

## Возможности админа в боте

Если у вас роль **admin** или **manager**, доступны дополнительные кнопки:
- 📊 **Отчёт** — отчёт о продажах
- 📋 **Заказы** — управление всеми заказами
- ✏️ **Изменить статус** — изменение статуса заказа
