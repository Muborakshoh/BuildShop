# Каталог и Товары

## Просмотр категорий

1. Нажмите кнопку **«Товары»** в нижней навигационной панели.
2. Слева отображается список категорий.
3. Для просмотра товаров конкретной категории нажмите на её название.
4. Для просмотра всех товаров нажмите кнопку **«Все»**.

> **[Вставьте скриншот: Страница каталога с категориями слева и товарами в центре]**

## Поиск товаров

1. В верхней части страницы каталога расположена строка поиска.
2. Введите название товара — результаты отобразятся мгновенно.

> **[Вставьте скриншот: Строка поиска с введённым текстом и результатами]**

## Карточка товара

Каждый товар отображается в виде отдельной карточки:
- **Фото** — изображение товара
- **Название** — наименование товара
- **Цена** — стоимость в сомони
- **Наличие** — «В наличии» или «Нет в наличии»
- Кнопка **«В корзину»** — для добавления в корзину

> **[Вставьте скриншот: Карточка товара с ценой и кнопкой «В корзину»]**

## Страница товара

Для просмотра полной информации нажмите на карточку товара:

- Крупное изображение
- Полное описание
- Цена и единица измерения
- Количество на складе
- Выбор количества и добавление в корзину
- Отзывы и рейтинг

> **[Вставьте скриншот: Полная страница товара с фото, ценой, количеством и отзывами]**

## Написание отзыва

1. Перейдите на страницу товара.
2. В разделе **«Отзывы»** нажмите на звёзды (1-5).
3. Напишите текст отзыва.
4. Нажмите **«Отправить»**.
