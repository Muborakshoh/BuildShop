# Панель Администратора — Общая информация

## Доступ к панели администратора

Панель администратора доступна только пользователям со следующими ролями:
- **admin** — администратор (полный доступ)
- **manager** — менеджер (управление товарами и заказами)
- **seller** — продавец (просмотр заказов и товаров)

1. Войдите в систему.
2. В нижней навигационной панели нажмите кнопку **«Админ»**.

> **[Вставьте скриншот: Кнопка «Админ» в нижней панели]**

## Главная страница админки

На главной странице отображаются:
- **Общая статистика** — количество товаров, заказов, пользователей
- **Быстрые кнопки** — переход к различным разделам
- **Последние заказы** — список самых новых заказов

## Боковое меню

Боковое меню содержит следующие разделы:
- **Товары** — управление каталогом
- **Категории** — управление категориями
- **Заказы** — управление заказами
- **Пользователи** — управление пользователями (только admin)
- **Новости** — управление новостями
- **Отчёты** — просмотр отчётов о продажах

> **[Вставьте скриншот: Боковое меню со всеми разделами]**

## Управление категориями

1. Перейдите в раздел **«Категории»**.
2. Для добавления новой категории нажмите кнопку **«Добавить»**.
3. Введите название на трёх языках (таджикский, русский, английский).
4. Нажмите кнопку **«Сохранить»**.

> **[Вставьте скриншот: Форма добавления новой категории]**

## Управление заказами

1. Перейдите в раздел **«Заказы»**.
2. Отобразится список всех заказов.
3. Для изменения статуса нажмите на заказ.
4. Выберите новый статус и нажмите **«Подтвердить»**.

> **[Вставьте скриншот: Список заказов с кнопкой изменения статуса]**

## Управление новостями

1. Перейдите в раздел **«Новости»**.
2. Нажмите кнопку **«Новая новость»**.
3. Введите заголовок, текст и изображение.
4. Нажмите кнопку **«Опубликовать»**.

> **[Вставьте скриншот: Форма добавления новой новости]**

## Отчёты о продажах

1. Перейдите в раздел **«Отчёты»**.
2. Выберите период времени.
3. Отобразится отчёт о продажах:
   - Общий доход
   - Количество заказов
   - Самые популярные товары
